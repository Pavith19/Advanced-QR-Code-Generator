# Advanced QR Code Generator

![QR Code Generator Banner](https://hebbkx1anhila5yf.public.blob.vercel-storage.com/image-ZCuV0tjyx1BMvIq0c4mfAOCP2XrOXB.png)

A feature-rich, responsive QR code generator with customization options, built with pure HTML, CSS, and JavaScript. Generate, customize, save, and download QR codes with various styles and options.

## ✨ Features

- **Modern UI**: Clean, responsive interface with dark/light mode support
- **QR Code Customization**:
  - Multiple sizes (128×128 to 400×400)
  - Different file formats (PNG, JPEG, SVG)
  - Custom dot styles (square, dots, rounded)
  - Custom corner styles (square, rounded, extra rounded)
  - Custom colors for foreground and background
- **Border Options**:
  - Multiple border styles (solid, dashed, dotted, double, groove, ridge)
  - Customizable border color and width
- **Icon Integration**:
  - Add emoji to the center of QR codes
  - Upload custom icons
  - Adjust icon size
- **Save & Manage**:
  - Save QR codes to browser storage
  - View, load, and manage saved QR codes
  - Download QR codes in different formats
- **Responsive Design**: Works on desktop, tablet, and mobile devices
